# Fine Bridge AI Skills

Fine Bridge Technology (Thailand) Co., Ltd. 的AI助手工具包

## 📋 项目简介

本仓库包含Fine Bridge使用的Claude AI Skills、标准指令模板和最佳实践文档，用于：
- 🔍 自动化报价审查
- ⚙️ NC编程质量检查
- 💰 智能成本估算
- 📊 标准化工作流程

## 🎯 主要内容

### Skills
- **Quotation Review** - 报价单质量审查
- **NC Programming Review** - CNC程序审查  
- **Cost Estimation** - 智能成本估算（开发中）

### Templates
- 报价审查标准指令
- 报价审查快速指令

### Documentation
- 使用入门指南
- Team协作设置
- 最佳实践

## 🚀 快速开始

1. 浏览 `skills/` 文件夹查看可用的Skills
2. 访问 `templates/` 获取标准指令模板
3. 阅读 `docs/getting-started.md` 了解详细使用方法

```
### Step 2: 创建文件夹结构（15分钟）

**创建第一个Skill文件：**
```
1. 返回仓库主页
2. 点击 "Add file" → "Create new file"
3. 文件名输入：skills/quotation-review/SKILL.md
   （GitHub会自动创建 skills 和 quotation-review 文件夹）

4. 粘贴Quotation Review Skill的内容
   （从您之前创建的Skill中复制）

5. 滚动到底部
6. Commit message: "Add Quotation Review Skill"
7. 点击 "Commit new file"
```

重复以上步骤，创建：
```

建议：

4. 选择 "Make private"
5. 确认

- 公开：Skills框架和模板
- 私有：价格数据、成本数据、客户信息
  创建另一个Private仓库存储

- 只上传通用内容
- 不上传任何价格、成本、客户数据
- 可以展示技术能力
