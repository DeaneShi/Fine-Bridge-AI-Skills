## 第一部分：验收计划（Acceptance Plan）

### 1. 验收目标

确认交付物满足《需求说明书》的全部 P0 与不少于 80% 的 P1 需求，且系统在真实业务场景下稳定可用、安全合规、易于维护。

### 2. 验收阶段

```
开发完成 → 内部 QA → 试点验收 → UAT 验收 → 正式上线 → 试运行验收
   2 周        1 周        2 周         2 周          1 个月
```

| 阶段 | 责任方 | 关键里程碑 |
| --- | --- | --- |
| **内部 QA** | 开发团队 | 自动化测试通过率 ≥ 95%；冒烟测试全过 |
| **试点验收** | 1 名律师 + 1 名助理 | 完成 3 个真实案件全流程走查 |
| **UAT 验收** | 全所成员 | 完成验收用例库 100%（详见 §4） |
| **正式上线** | 项目组 | 数据迁移 + 全员账号开通 + 培训完成 |
| **试运行验收** | 律所合伙人 | 30 天内 P0/P1 故障 = 0；满意度 ≥ 4/5 |

### 3. 验收准入条件

签署 UAT 启动前必须满足：
- [ ] 所有 P0 功能开发完成并通过内部 QA
- [ ] 部署到生产环境（非本地开发机）
- [ ] 完整的种子数据（至少 5 个示例案件、20 个示例卷宗）
- [ ] 用户手册 v1.0 完成
- [ ] 备份脚本可执行并通过 1 次恢复演练
- [ ] 性能测试报告达 NFR-PERF 目标
- [ ] 安全自查清单（§7）全部通过

### 6. 缺陷分级

- [ ] 依赖项无已知高危 CVE（npm audit / pip-audit）

### 14. 通关考核标准

每位用户必须通过对应角色的考核才能获得正式账号权限。

#### 14.1 lawyer 通关清单（45 分钟，三大业务线全覆盖）

**诉讼仲裁业务线**：
- [ ] 创建一个新案件，录入 2 名当事人
- [ ] 上传 3 份卷宗（含 1 份扫描件，需触发 OCR）
- [ ] 在智能问答中提问并获得引用法条的回答
- [ ] 用模板生成一份**起诉状**，导出为 .docx
- [ ] 用模板生成一份**证据目录 + 三性分析**
- [ ] 用模板生成一份**反诉状**或**管辖权异议申请书**
- [ ] 完成一次虚拟法庭至少到"法庭辩论"阶段

**法律顾问业务线**：
- [ ] 提交一份合同审查请求并查看 AI 风险点
- [ ] 出具一份合同审查意见（修订建议）

**非诉法律项目业务线**（覆盖业主四阶段工作法）：
- [ ] 创建一个 M&A 项目档案
- [ ] **阶段 A**：录入至少 5 条商业诉求（含 1 条 Must、底线已写入）；选定交易结构方案
- [ ] **阶段 A**：制定立场矩阵中 1 个议题的"理想 / 目标 / 底线"
- [ ] 一键生成尽调清单并标注 P0 优先级
- [ ] 上传 1 份目标方资料并登记一条尽调发现
- [ ] 把该尽调发现一键转化为谈判议题
- [ ] **阶段 B**：创建 R1 谈判轮次并填写会议纪要；将议题状态从"提出中"切到"谈判中"
- [ ] **阶段 B**：登记 1 条客户决策（DEC-1），与议题关联
- [ ] **阶段 C**：建立条款映射（议题 ↔ SPA 条款）；触发文本闭合检查
- [ ] 一键生成尽调报告初稿
- [ ] **阶段 D**：生成程序清单；标记反垄断申报为"准备中"

**通用**：
- [ ] 在使用手册中找到"上诉期计算"章节

#### 14.2 assistant 通关清单（20 分钟）
- [ ] 接受被分配的案件
- [ ] 上传 5 份卷宗并按类别分类
- [ ] 维护案件时间线，添加 3 条事件
- [ ] 用模板生成一份律师函

#### 14.3 partner 通关清单（30 分钟）
- [ ] 浏览全所案件列表，按律师筛选
- [ ] 审批 1 份超阈值折扣报价单
- [ ] 标记 1 份文书"已审核"
- [ ] 配置"敏感案件不上 AI"开关
- [ ] 在客户档案中查看一个客户的全部商务记录
- [ ] 审核并发送 1 份顾问单位月度服务报告
- [ ] 查看顾问业务数据看板

#### 14.4 admin 通关清单（半天）
- [ ] 从空环境完成一次部署
- [ ] 创建/禁用/重置用户
- [ ] 执行一次手动备份并验证文件
- [ ] 模拟数据库故障并从备份恢复
- [ ] 查看监控仪表盘并解读 Claude 用量

### 15. 培训效果评估

每次培训结束发放问卷（5 分制）：
- 内容清晰度
- 节奏合理度
- 实用性
- 讲师讲解
- 后续意愿（"我能独立操作此模块"评分）

合格线：所有维度均分 ≥ 4.0；后续意愿 ≥ 4.0。否则补训。

### 16. 持续培训机制

- **新人入职**：1 对 1 集中培训 1 天，由 admin 或资深用户带教
- **季度回顾**：每季度 1 次"使用习惯回顾会"，1 小时
- **新功能上线**：每次大版本更新发布"What's New"邮件 + 30 分钟在线讲解
- **使用反馈**：手册"是否有用"反馈每月汇总，识别培训盲点
