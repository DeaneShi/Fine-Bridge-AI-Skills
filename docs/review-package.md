**评审目标**：在开工前，由律所合伙人确认项目的**业务范围、合规边界、预算、工期**四件大事，并在最后签字定稿。

**评审材料**：

## 一、执行摘要（5 分钟）

### 1.1 项目要做什么

为律所搭建一套**所内浏览器访问**的 AI 辅助办案系统，覆盖案件**全生命周期**（接案 → 卷宗 → 问答 → 文书 → 庭审准备 → 跟踪 → 结案），核心引擎为 **Claude API**。

### 1.2 一句话价值

> **把律师从"查法条、写文书、催期限"中解放出来，把精力还给"判断、谈判、出庭"。**

| 改变 | 现状 | 上线后目标 |
| --- | --- | --- |
| 接案到立案耗时 | 5-7 天 | 减少 30% |
| 文书起草耗时 | 4-8 小时/份 | 减少 50% |
| 期限逾期事故 | 偶发 | 0 |
| 利冲漏检 | 偶发 | 0（系统强制） |
| 助理培训周期 | 4 周 | 2 周 |

### 1.3 三大业务线 × 10 大模块（v2.0 重大调整）

系统按律所**三大业务线**组织，而不是只围着"案件"转：

```
─────────────── 通用底座（跨三条业务线）────────────────
  ① 账户管理 P0           ② 客户与卷宗 P0
  ③ 智能问答 P0           ④ 文件输出 P0（按业务线分类模板）
  ⑤ 商务模块 P1           ⑥ 使用手册 P0

─────────────── 业务线 ① 常年法律顾问 ────────────────
  ⑦ 法律顾问服务模块 P0
     合同审查 / 法律意见书 / 定期工作汇报 / 法律咨询解答（业主明确 4 子功能）

─────────────── 业务线 ② 诉讼仲裁案件代理 ───────────
  ⑧ 诉讼仲裁案件管理 P0
     案件分析与资料处理 / 司法文书全套 / 模拟法庭打磨（业主明确 3 子需求）
  ⑩ 虚拟法庭（外脑）P1

─────────────── 业务线 ③ 非诉法律项目 ⭐ 业主主战场 ──
  ⑨ 非诉法律项目模块 P0（v2.1 按业主四阶段工作法重组）
     阶段 A 商业诉求拆解：商业诉求清单 / 交易结构选项 / 立场矩阵
     阶段 B 谈判过程管理：谈判轮次 / 议题追踪器 / 客户决策记录
     阶段 C 谈判成果固化：议题↔条款映射 / 文本闭合检查 / 交易文本 / 配套文本
     阶段 D 程序性流程闭环：工商/税务/外汇/反垄断/行业等程序清单与办理追踪
     横向：尽调清单 / 尽调报告 / 法律意见书 / 交付物追踪
     首批深度支持 M&A，业主以并购非诉见长
```

> **v2.1 非诉模块哲学校正**：业主明确律师价值不在"输出文档"而在"理解并优化交易商业实质，清晰界定我方商业诉求，促进委托人商业利益实现"。模块重组贴合业主原话四阶段工作法："① 与客户沟通讨论 → ② 多轮次和对手方谈判 → ③ 谈判成果书面固化 → ④ 程序性流程"。

> **诉讼文书全套**（已写入模板与需求）：起诉状、答辩状、**反诉状、管辖权异议申请书**、上诉状、**再审申请书、执行申请书、保全申请书、仲裁申请书、证据目录、证据三性分析**、回避/延期举证/调取证据/鉴定/撤诉等各类规范性文件。

### 1.4 关键数字（v2.1 再调整）

| 项 | 数字 |
| --- | --- |
| 工期 | **20 周**（v2.0 → v2.1：18.5 → 20，因非诉新增谈判管理 + 商业诉求 + 程序闭环三大能力） |
| 上线日期 | **2026-10-04**（v2.0 → v2.1：09-20 → 10-04） |
| 硬件投入 | **≤ ¥30,000**（一次性） |
| API 月费 | **USD 200-800**（非诉项目大文档处理量上升，预计上限上调；启用 Prompt Caching 后整体节省 75%） |
| 用户规模 | 3-5 人，扩展上限 10 人 |
| 部署位置 | **所内局域网** + Tailscale 异地 |
| 数据合规 | 案件 / 项目内容**会发送至 Claude API**（境外）；提供"敏感案件 / 项目不上 AI"开关 |

### 1.5 一张图看清楚最大的合规权衡

```
                ┌─────── 选项 A：全部上 AI ───────┐
                │  ✅ 效率最大化                   │
                │  ❌ 全部案件内容发送境外         │
                │  ❌ 当事人需签数据出境告知书     │
                └──────────────────────────────────┘

   推荐 →   ┌─────── 选项 B：可开关上 AI ─────┐
                │  ✅ 律师按需勾选"敏感不上 AI" │
                │  ✅ 涉密案件系统层强制拦截    │
                │  ⚠️ 律师承担分类判断责任      │
                └───────────────────────────────────┘

                ┌─────── 选项 C：全部不上 AI ──────┐
                │  ✅ 完全合规，零数据出境          │
                │  ❌ 失去 AI 价值，等于不做项目    │
                └───────────────────────────────────┘
```

> **当前方案默认 B**。如合伙人选择 A 或 C，工期与价值会显著变化，请在 §三 决策项 D-01 表态。
