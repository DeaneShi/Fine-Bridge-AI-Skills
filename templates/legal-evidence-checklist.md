## 4. 证据三性分析

> 对每一项证据填写。

### 证 1 —— 《借款合同》

| 维度 | 分析 |
| --- | --- |
| 真实性 | 原件留存，签字真实，无涂改痕迹。 |
| 合法性 | 取得方式合法，签订符合法律形式要求。 |
| 关联性 | 直接证明借贷合意，与诉请有直接关联。 |
| 证明力 | 高 |
| 风险点 | 对方可能否认签字真实性 → 预案：申请笔迹鉴定。 |

### 证 2 —— 微信聊天记录

| 维度 | 分析 |
| --- | --- |
| 真实性 | 已经公证保全，主体身份可通过手机号 + 实名认证比对。 |
| 合法性 | 当事人本人对话，不涉及侵犯隐私。 |
| 关联性 | 内容直接涉及借款催讨。 |
| 证明力 | 中 |
| 风险点 | 对方可能否认账号实际使用人 → 预案：申请法院调取微信实名信息。 |

## 7. 特殊证据规则提示

- [ ] **电子数据**：保管链清晰，建议公证或区块链存证；提交时附形成、收集、传输、保存方式说明。
- [ ] **视听资料**：取得方式不得侵害他人合法权益、不得违反法律禁止性规定。
- [ ] **证人证言**：申请证人出庭须于举证期届满前 10 日提出。
- [ ] **域外证据**：在中华人民共和国领域外形成的证据，依法应办理公证、认证或履行《海牙取消认证公约》手续（涉港澳台另行处理）。
- [ ] **涉密/隐私证据**：申请不公开质证。
- [ ] **新证据**：超过举证期的，需说明理由（非因故意或重大过失）。
