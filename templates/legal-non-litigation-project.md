# 非诉法律项目工作流模板（Non-Litigation Project Templates）

> 配套 Skill：`legal-firm-agent`（非诉项目业务线）
> 适用项目类型：股权并购、资产收购、私募融资、IPO、重组、合规等
> 本文件汇总四类核心交付物的模板：① 尽调清单 / ② 尽调资料请求函 / ③ 法律尽职调查报告 / ④ 交易文本骨架
>
> ⚠️ 非诉项目高度因案制宜，模板**仅作起草起点**，必须由主办律师按交易具体情况裁剪。

### 尽调报告要点 ⚠️
- **执行摘要必须独立成段**，能让客户决策层 5 分钟看完。
- **风险等级用语统一**（高 / 中 / 低），并在尾部说明分级标准。
- **责任限定段落必须显眼**：基准日、资料来源、本所核实责任范围。
- **建议必须可执行**：不写"建议进一步关注"，要写"建议要求卖方在 SPA 第 X 条作出 [具体陈述]"。
- **保密水印**：每页右下角"高度保密"+ 客户名称水印，防外泄。

## 五、交易文本骨架（M&A 主协议）

> 以股权转让协议（SPA）为例。每节列出**框架要点**，律师按项目具体情况展开。

```
股 权 转 让 协 议（SPA）

转让方（卖方）：____
受让方（买方）：____
标的公司：____

定义与解释：（1.1 - 1.X）
- 标的股权 / 交易对价 / 交割日 / 交割先决条件 / 关键人员 / ……

第一条  股权转让
1.1 标的股权
1.2 转让对价
1.3 价款支付方式与时间表
1.4 价款托管 / 锁箱机制（如有）

第二条  陈述与保证（Reps & Warranties）
2.1 卖方陈述（含目标公司基本情况、股权权属、财务、合同、不动产、知产、员工、税务、合规、诉讼）
2.2 买方陈述
2.3 持续陈述与保证（基本陈述至交割后多年）

第三条  交割先决条件（Conditions Precedent）
3.1 卖方义务的先决条件
3.2 买方义务的先决条件
3.3 交割先决条件未满足的处理

第四条  过渡期安排（Pre-Closing Covenants）
4.1 业务正常运营义务
4.2 不得进行的事项（白名单 / 黑名单）
4.3 信息持续披露

第五条  交割（Closing）
5.1 交割时间与地点
5.2 交割文件
5.3 交割步骤

第六条  交割后承诺（Post-Closing Covenants）
6.1 不竞争
6.2 不挖角
6.3 协助过渡
6.4 信息保护

第七条  违约与赔偿（Indemnification）
7.1 违约情形
7.2 赔偿范围与限额（Cap / Basket）
7.3 赔偿期限
7.4 直接 vs 间接损失

第八条  陈述与保证保险（W&I Insurance）（如适用）

第九条  对赌与业绩承诺（如适用）

第十条  争议解决
10.1 适用法律
10.2 争议解决机构（仲裁 / 诉讼）

第十一条  生效与其他
11.1 生效条件
11.2 通知
11.3 修改与放弃
11.4 转让
11.5 完整协议
11.6 副本

签字页

附件：
A：标的股权与对价计算
B：交割文件清单
C：陈述与保证披露函（Disclosure Letter）
D：过渡期白名单 / 黑名单
E：关键人员竞业限制范围
```

### SPA 起草要点 ⚠️
- **披露函（Disclosure Letter）是关键文件**：卖方对一般陈述与保证的具体豁免，需与陈述与保证条款逐条对应。
- **赔偿条款的量化设计**：起赔金额（Basket / Threshold）、赔偿上限（Cap，常见 10-30% 交易对价）、赔偿期限（一般陈述 1-2 年，基本陈述 5-10 年，税务陈述跟随税务追溯期）。
- **价款锁箱（Locked Box）vs 交割调整（Closing Accounts）**：选择影响整个文本结构。
- **对赌**：避免无效条款（如对未上市公司的不合理回购约定可能因损害公司利益被认定无效，参考"海富案"及《九民纪要》）。
