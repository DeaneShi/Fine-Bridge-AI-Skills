# 法律文书起草模板（Legal Document Drafting）

> 配套 Skill：`legal-firm-agent`｜阶段 ⑤
> **诉讼仲裁业务线全套司法文书模板**。涵盖：
> - 起诉与答辩：民事起诉状、行政起诉状、民事答辩状、**反诉状**
> - 二审与再审：民事/刑事上诉状、**再审申请书 / 申诉书**
> - **管辖与程序异议**：**管辖权异议申请书**、回避申请、延期举证申请、调取证据申请、鉴定申请、撤诉申请
> - **证据组卷**：**证据目录**、**证据整理表 / 三性分析**、举证清单
> - 代理与意见：代理意见、辩护词、法律意见书
> - **仲裁专用**：**仲裁申请书**、**仲裁答辩书**
> - **执行与保全**：**执行申请书**、**保全申请书**
> - 函件：律师函、催告函
>
> 起草后必须使用文末"自检清单"逐项核对。

---

## 一、民事起诉状

```
民 事 起 诉 状

原告：[姓名/名称]，[性别]，[出生日期]，[民族]，[住所地/注册地址]，[身份证号/统一社会信用代码]，联系电话：[XXX]。
[法定代表人/负责人：XXX，职务：XXX]
委托诉讼代理人：[XXX]，[XX 律师事务所] 律师，联系电话：[XXX]。

被告：[姓名/名称]，[同上格式]。
（如有多被告、第三人，按上述格式逐一列明）

诉讼请求：
一、请求判令被告……（金额到元、日期到日、行为请求要明确范围）；
二、请求判令被告……；
三、本案诉讼费、保全费、保全担保费、律师费等由被告承担。

事实与理由：
一、[事实段落 1：按时间顺序陈述，引用证据编号]
二、[事实段落 2]
三、[法律分析：诉讼请求 → 请求权基础 → 构成要件 → 本案情况]

综上，被告的行为已构成……，依据《XXX》第 X 条、第 X 条之规定，特向贵院提起诉讼，请求依法判如所请。

此致
[XXX 人民法院]

附：
1. 本起诉状副本 [对方人数] 份；
2. 证据材料清单及证据复印件 [份数] 份；
3. 原告身份证明、授权委托书、律师事务所函。

具状人（签名/盖章）：___________
日期：________年____月____日
```

### 起诉状要点
- 当事人信息齐全，特别是被告的姓名/名称、住址必须能用于送达。
- 诉讼请求**可执行、可量化**：金额诉请要写明本金 + 利息（起算日、利率、止付日）；行为诉请要明确"做什么、做到什么程度"。
- 事实与理由按时间或逻辑顺序展开，每段引用对应证据编号。
- 法律依据放在事实之后或独立段落，**精确到款项**。
- 管辖法院名称必须正确（全称）。

## 二、民事答辩状

```
民 事 答 辩 状

答辩人：[同上格式]
被答辩人：[同上格式]

答辩人因 [被答辩人] 诉答辩人 [案由] 一案，现提出答辩意见如下：

答辩意见：
一、[针对原告诉请逐一答辩]：原告第 X 项诉请缺乏事实和法律依据，应予驳回。理由是……
二、[管辖异议如有，单独提出，不得在答辩状中合并]
三、[反诉如有，另行提交反诉状]

事实与理由：
[逐一反驳原告事实陈述，引用我方证据]
[提出我方法律观点：抗辩事由、请求权消灭事由、合同效力问题、诉讼时效抗辩等]

综上，请求贵院依法驳回原告的全部诉讼请求。

此致
[XXX 人民法院]

答辩人（签名/盖章）：___________
日期：________年____月____日
```

### 答辩状要点
- **答辩期 15 日**（涉外 30 日），逾期不答辩不影响审理但丧失主动陈述机会。
- **管辖异议须在答辩期内单独提出**（《民事诉讼法》第 130 条），切勿与实体答辩合并。
- **反诉**应在举证期届满前提出，与本诉具有牵连关系。
- 答辩思路：先程序（管辖、主体、时效），再实体（事实、法律）。

## 三、民事上诉状

```
民 事 上 诉 状

上诉人（一审 [原告/被告]）：[XXX]
被上诉人（一审 [原告/被告]）：[XXX]

上诉人因与被上诉人 [案由] 一案，不服 [XXX 人民法院]（YYYY）X 民初 X 号民事判决，现提出上诉。

上诉请求：
一、请求依法撤销 [XXX 人民法院]（YYYY）X 民初 X 号民事判决第 X 项；
二、请求改判……（或：发回重审）；
三、一、二审诉讼费由被上诉人承担。

上诉理由：
一、一审认定事实错误：……
二、一审适用法律错误：……
三、一审违反法定程序：……（如有）

综上，请求二审法院依法支持上诉人的上诉请求。

此致
[XXX 人民法院]（应当通过原审法院递交）

上诉人（签名/盖章）：___________
日期：________年____月____日
```

### 上诉状要点
- **上诉期**：判决 15 日，裁定 10 日，自送达次日起算（涉外当事人 30 日）。⚠️ **绝对不可逾期**。
- **递交方式**：通过原审法院递交，由原审法院移送二审法院。
- **上诉理由**应当对应《民事诉讼法》关于二审审理范围的规定（事实/法律/程序）。

```
关于 [事项名称] 之
法 律 意 见 书

致：[委托方]

文号：[XXX 律师事务所]法意字（YYYY）第 X 号

[简要陈述委托事项的事实背景]

二、委托事项
[明确律师被委托回答的法律问题，分点列出]

三、所依据的资料
1. 委托方提供的：……
2. 律师调取的：……
3. 法律法规及司法解释：……
（特别说明：本意见基于上述资料及现行有效法律出具，对未提供资料的部分及法律变更不承担法律责任）

四、法律分析
（一）关于问题 1：……
（二）关于问题 2：……

五、法律意见
1. ……
2. ……

六、风险提示
1. ……
2. ……

七、声明
1. 本意见仅供委托方就本事项使用，不得用于其他目的，不得提供给第三方。
2. 本意见基于截至出具日的中华人民共和国大陆地区现行有效法律。
3. ……

[XX 律师事务所]（盖章）
经办律师：___________（签名）
```

### 法律意见书要点
- 假设与依据要写清楚：基于"客户提供的资料完整真实"的假设。
- 区分**法律意见**与**商业建议**。
- 对每一项法律问题给出明确结论 + 不确定性说明。
- 风险提示应当具体可操作。

## 六、律师函

```
律 师 函

[文号：(YYYY)XX 所律函字第 X 号]

致：[XXX]
（联系地址：____）

[XX 律师事务所] 接受 [XXX]（以下简称"委托人"）的委托，指派本律师就委托人与贵方之间 [事项] 的相关事宜，特此致函如下：

一、事实陈述
……

二、法律分析
根据《XXX》第 X 条之规定，……

三、本所要求
为维护委托人合法权益，本所特此要求贵方于本函送达之日起 [X] 日内，[具体行为]。逾期未履行的，委托人将依法采取以下措施：
1. 向有管辖权的人民法院/仲裁机构提起诉讼/仲裁；
2. 申请财产保全；
3. 追究贵方因此产生的全部经济损失（包括但不限于律师费、诉讼费、保全费、保全担保费、差旅费等）。

特此函告。

[XX 律师事务所]（盖章）
经办律师：___________（签名）
日期：________年____月____日
```

### 律师函要点
- 措辞**严谨克制**，避免威胁、侮辱性语言。
- 主张的事实与法律依据要准确，避免被对方反咬"虚假陈述"。
- 设定明确履行期限和不履行的后果。
- 通过 EMS 或公证送达，保留送达凭证。

## 七、反诉状

```
民 事 反 诉 状

反诉人（本诉被告）：[XXX，同前格式]
被反诉人（本诉原告）：[XXX，同前格式]

反诉人因 [被反诉人] 与 [反诉人] 之间 [本诉案由] 一案（贵院已立案，案号：(YYYY) X 民初 X 号），现根据《民事诉讼法》第 51 条、《最高人民法院关于适用〈中华人民共和国民事诉讼法〉的解释》第 232-233 条之规定，对被反诉人提起反诉。

反诉请求：
一、请求判令被反诉人……（金额到元，行为请求要明确）；
二、本反诉诉讼费由被反诉人承担。

事实与理由：
一、本诉与反诉的牵连关系：[说明反诉与本诉基于同一法律关系或基于同一事实]
二、反诉事实陈述：……
三、法律依据：《XXX》第 X 条……

综上，反诉人的反诉请求事实清楚、证据确凿、于法有据，请求贵院在审理本诉时一并审理本反诉。

此致
[XXX 人民法院]

反诉人（签名/盖章）：___________
日期：________年____月____日

附：反诉状副本 [被反诉人人数] 份；证据材料目录及复印件 [份]。
```

### 反诉状要点
- **反诉与本诉的牵连关系**是受理前提：基于同一法律关系或同一事实。
- **反诉时点**：在举证期届满前提出（《民诉法解释》第 232 条）。
- **管辖**：反诉一般由本诉管辖法院管辖；标的额合并计算可能改变级别管辖，需评估。
- 反诉成立后，本诉与反诉合并审理，分别裁判。

## 八、管辖权异议申请书

```
管 辖 权 异 议 申 请 书

申请人（本诉被告）：[XXX，同前格式]
被申请人（本诉原告）：[XXX，同前格式]

申请人因 [被申请人] 诉申请人 [案由] 一案（贵院案号：(YYYY) X 民初 X 号），认为贵院对本案无管辖权，根据《民事诉讼法》第 130 条之规定，特提出管辖权异议申请。

异议请求：
一、请求贵院依法将本案移送 [有管辖权的 XXX 人民法院] 审理。

异议理由：
一、本案不应由贵院管辖，应当由 [XXX 法院] 管辖。理由如下：
（一）从地域管辖看……（如：被告住所地为 XX，合同履行地为 XX，依《民诉法》第 23/24/25 条……）
（二）从协议管辖看……（如：双方在 XX 合同第 X 条约定争议由 XX 法院管辖……）
（三）从专属管辖看……（如：本案系不动产纠纷，依《民诉法》第 33 条由不动产所在地法院专属管辖……）
（四）从级别管辖看……（如：本案标的额超过本院管辖标准……）

二、依据《民事诉讼法》第 130 条、第 36 条之规定，贵院应当将本案移送有管辖权的法院审理。

综上，请求贵院依法将本案移送 [XXX 人民法院] 审理。

此致
[XXX 人民法院]

申请人（签名/盖章）：___________
日期：________年____月____日
```

### 管辖权异议要点 ⚠️
- **必须在答辩期内提出**（《民诉法》第 130 条），通常为收到起诉状副本之日起 15 日（涉外 30 日）。
- **必须独立提出**，不得与实体答辩合并；提出管辖异议本身不构成应诉答辩。
- 异议被驳回的，应在 10 日内向上一级人民法院上诉。
- 即使提出管辖异议，**举证期、应诉答辩期不停止计算**——异议不被支持时仍要应诉。

## 九、再审申请书 / 申诉书

```
民 事 再 审 申 请 书

再审申请人（原审 [原告/被告/第三人]）：[XXX]
被申请人（原审 [对方]）：[XXX]

再审申请人因不服 [XXX 人民法院]（YYYY）X 民终 X 号民事判决（已经发生法律效力），根据《民事诉讼法》第 207 条之规定，特申请再审。

再审请求：
一、请求依法撤销 [XXX 人民法院]（YYYY）X 民终 X 号民事判决；
二、请求依法改判……（或：发回重审）。

申请再审的事实与理由：
本判决符合《民事诉讼法》第 207 条 [第 X 项] 规定的再审情形：
一、[选择适用条款，例如]：
   - 第 1 项：有新的证据，足以推翻原判决——[本案新证据情况]
   - 第 2 项：原判决认定的基本事实缺乏证据证明——[具体事项]
   - 第 6 项：原判决适用法律确有错误——[具体错误]
   - 第 11 项：违反法定程序，影响公正审判——[具体违反]

二、[展开事实与法律分析]

综上，本判决存在再审法定事由，请求贵院依法立案再审。

此致
[XXX 人民法院]（向作出原生效判决法院的上一级法院申请，符合特定情形的可向同级或最高法申请）

再审申请人（签名/盖章）：___________
日期：________年____月____日
```

### 再审申请要点 ⚠️
- **申请期限**：判决生效后 6 个月内（特殊事由 3 个月内）。
- **管辖**：原则上向作出生效判决法院的上一级法院提出。
- **再审事由必须对应《民诉法》第 207 条 13 项之一**，逐条对照说明。
- 仅"对判决不满"不是再审事由；必须有法定情形 + 充分证据。

## 十、保全申请书

```
财产保全申请书

申请人：[XXX，同前格式]
被申请人：[XXX，同前格式]

申请事项：
一、请求依法查封 / 扣押 / 冻结被申请人名下财产，价值人民币 [XXX] 元；
二、请求采取保全措施所需费用由被申请人承担。

事实与理由：
一、本案纠纷情况：……
二、采取保全的必要性：被申请人 [转移财产 / 拒不履行 / 财产可能灭失]……
三、申请人愿意提供 [现金 / 银行保函 / 担保公司保函 / 财产] 作为担保，担保金额为 [XXX] 元。

财产线索：
1. 被申请人在 [XXX 银行] 账户：账号 ______，约 ______ 元；
2. 被申请人名下不动产：[详细地址]；
3. 被申请人名下车辆：车牌号 ______；
4. 被申请人在 [XXX 公司] 持有股权：______ %。

依据《民事诉讼法》第 103-110 条之规定，请求贵院依法准许。

此致
[XXX 人民法院]

申请人（签名/盖章）：___________
日期：________年____月____日
```

### 保全要点
- **诉前保全**：依《民诉法》第 104 条，30 日内不起诉应解除保全。
- **诉中保全**：在诉讼过程中提出。
- **担保**：通常需提供保全标的 30%-100% 担保（各地法院差异大）；常用银行保函、保险公司保函。
- **保全金额**：不得超过诉讼请求金额。
- **错误保全责任**：保全错误造成被申请人损失的，申请人需赔偿，故担保不可省。

## 十一、执行申请书

```
强 制 执 行 申 请 书

申请执行人（原审 [原告/被告]）：[XXX]
被执行人（原审 [对方]）：[XXX]

申请执行人与被执行人 [案由] 一案，已由 [XXX 人民法院]（YYYY）X 民初 X 号民事判决（裁定 / 调解书）作出，该判决已于 YYYY-MM-DD 发生法律效力。判决主文要求被执行人 ______，但被执行人至今未履行义务。

申请执行事项：
一、请求执行 [XXX 人民法院]（YYYY）X 民初 X 号判决主文第 X 项：……（金额、行为）；
二、加倍支付迟延履行期间的债务利息（自 YYYY-MM-DD 起至实际履行之日止）；
三、本案执行费由被执行人承担。

被执行人财产线索：
1. 银行账户：……
2. 不动产：……
3. 股权：……
4. 其他可执行财产：……

依据《民事诉讼法》第 240 条之规定，特申请贵院依法强制执行。

此致
[XXX 人民法院]（一审法院或同级被执行的财产所在地法院）

申请人（签名/盖章）：___________
日期：________年____月____日
```

### 执行申请要点 ⚠️
- **申请执行期间**：2 年（《民诉法》第 246 条），自履行期间最后一日起算。
- **申请执行的法院**：第一审人民法院或与第一审同级的被执行的财产所在地法院。
- **必备材料**：执行申请书 + 生效判决/裁定/调解书原件 + 申请人身份证明 + 财产线索 + 送达地址确认书。
- **加倍利息**：判决确定的金钱给付逾期未履行的，按《民诉法》第 264 条加倍支付迟延履行期间的债务利息。

### 仲裁申请要点
- **仲裁的前提**：双方有有效仲裁协议或合同中的仲裁条款。
- **仲裁机构**：协议指定的具体仲裁委（如 中国国际经济贸易仲裁委员会、北京仲裁委员会、上海国际仲裁中心、地方仲裁委等），不得"约定不明"。
- **一裁终局**：仲裁裁决一般不可上诉；只能依《仲裁法》第 58 条申请撤销或不予执行。
- **保密性**：仲裁不公开审理（除非当事人协议公开）。

- **证明事项**：每项证据要写清楚"证明什么"，**避免一证多用**。

## 十四、证据整理表 / 三性分析（按待证事实组织）

```
证 据 整 理 表 / 三 性 分 析

案号：(YYYY) X 民初 X 号

# 待证事实 1：[借贷合意成立]
| 证据 | 真实性 | 合法性 | 关联性 | 证明力 | 风险与预案 |
| --- | --- | --- | --- | --- | --- |
| 证 1 借款合同 | 原件，签字真实 | 取得方式合法 | 直接相关 | 高 | 对方可能否认签字 → 笔迹鉴定预案 |
| 证 2 微信聊天 | 公证保全 | 合法 | 内容相关 | 中 | 对方否认账号 → 申请调取实名 |

# 待证事实 2：[款项实际交付]
| 证据 | 真实性 | 合法性 | 关联性 | 证明力 | 风险与预案 |
| --- | --- | --- | --- | --- | --- |
| 证 3 银行流水 | 银行打印 | 合法 | 直接相关 | 高 | / |

# 对方可能提交的证据预判（质证预案）
| 对方证据 | 我方质证意见 | 反证 |
| --- | --- | --- |
| 还款凭证 | 真实性认可 / 否认；金额对应不上 | 调取流水反驳 |

整理人：___________  日期：________年____月____日
```

### 证据整理要点
- **以"待证事实"为中心**组织，不是以"证据本身"为中心。
- 每项待证事实**至少 1 项证据**支撑；薄弱处提前补强。
- **三性**对应 真实性 / 合法性 / 关联性，是质证的法定维度。
- **预案**栏：预判对方质证 + 我方应对，开庭前必备。

## 十六、文书自检清单 ⚠️

### 通用项
- [ ] 当事人信息完整、准确（自然人含身份证号；法人含统一社会信用代码、法定代表人）
- [ ] 法院/仲裁机构名称使用全称
- [ ] 案由准确（参照《民事案件案由规定》）
- [ ] 法律依据精确到款项，且现行有效
- [ ] 金额、日期、人名前后一致
- [ ] 没有错别字、标点符号规范
- [ ] 落款、签名、盖章位置预留
- [ ] 附件清单与正文引用一一对应
- [ ] 份数 = 法院 1 份 + 对方人数 + 自留 1 份

### 起诉状专项
- [ ] 诉讼请求每一项都有对应的事实和法律依据
- [ ] 金额请求计算到元，利息有起算日、利率、止付日
- [ ] 行为请求明确具体内容
- [ ] 管辖法院正确（级别 + 地域 + 协议/专属）
- [ ] 标的额计算与诉讼费预交一致

### 答辩状专项
- [ ] 在答辩期内（15 日 / 涉外 30 日）
- [ ] 管辖异议（如有）单独提出
- [ ] 反诉（如有）单独提交反诉状
- [ ] 已逐一回应原告诉请

### 上诉状专项 ⚠️ 期限不可逾越
- [ ] 在上诉期内（判决 15 日 / 裁定 10 日 / 涉外 30 日）
- [ ] 通过原审法院递交
- [ ] 上诉理由对应法定二审审查范围
- [ ] 已交纳上诉案件受理费

### 反诉状专项
- [ ] 反诉与本诉具有牵连关系
- [ ] 在举证期届满前提出
- [ ] 评估反诉与本诉合并后的级别管辖

### 管辖权异议专项 ⚠️ 必须答辩期内
- [ ] 在答辩期内独立提出（不与实体答辩合并）
- [ ] 已具体说明本院无管辖权 + 应由哪个法院管辖
- [ ] 提示当事人：异议提出后举证期 / 答辩期不停止

### 再审申请专项 ⚠️ 期限严格
- [ ] 在判决生效后 6 个月（特殊事由 3 个月）内
- [ ] 再审事由对应《民诉法》第 207 条具体项
- [ ] 向作出生效判决的上一级法院提出（除特殊情形）

### 保全申请专项
- [ ] 担保已落实（金额、形式合法院要求）
- [ ] 财产线索具体可执行（账号、地址、持股比例）
- [ ] 保全金额不超过诉讼请求金额
- [ ] 提示当事人保全错误的赔偿责任

### 执行申请专项 ⚠️
- [ ] 在 2 年申请执行期内
- [ ] 生效判决/裁定/调解书原件齐备
- [ ] 已主张加倍迟延履行利息

### 仲裁申请专项
- [ ] 仲裁协议有效（机构明确、事项明确、表意真实）
- [ ] 提交至协议指定的仲裁机构
- [ ] 仲裁费已预交

### 证据目录与三性分析专项
- [ ] 编号连续，与正文引用一致
- [ ] 每项证据明确证明事项，不一证多用
- [ ] 三性分析逐证完成
- [ ] 已识别对方可能质证点并准备反驳
