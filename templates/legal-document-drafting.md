# 法律文书起草模板（Legal Document Drafting）

> 配套 Skill：`legal-firm-agent`｜阶段 ⑤
> 包含：民事起诉状、民事答辩状、上诉状、代理意见、法律意见书、律师函。
> 起草后必须使用文末"自检清单"逐项核对。

---

## 一、民事起诉状

```
民 事 起 诉 状

原告：[姓名/名称]，[性别]，[出生日期]，[民族]，[住所地/注册地址]，[身份证号/统一社会信用代码]，联系电话：[XXX]。
[法定代表人/负责人：XXX，职务：XXX]
委托诉讼代理人：[XXX]，[XX 律师事务所] 律师，联系电话：[XXX]。

被告：[姓名/名称]，[同上格式]。
（如有多被告、第三人，按上述格式逐一列明）

诉讼请求：
一、请求判令被告……（金额到元、日期到日、行为请求要明确范围）；
二、请求判令被告……；
三、本案诉讼费、保全费、保全担保费、律师费等由被告承担。

事实与理由：
一、[事实段落 1：按时间顺序陈述，引用证据编号]
二、[事实段落 2]
三、[法律分析：诉讼请求 → 请求权基础 → 构成要件 → 本案情况]

综上，被告的行为已构成……，依据《XXX》第 X 条、第 X 条之规定，特向贵院提起诉讼，请求依法判如所请。

此致
[XXX 人民法院]

附：
1. 本起诉状副本 [对方人数] 份；
2. 证据材料清单及证据复印件 [份数] 份；
3. 原告身份证明、授权委托书、律师事务所函。

具状人（签名/盖章）：___________
日期：________年____月____日
```

### 起诉状要点
- 当事人信息齐全，特别是被告的姓名/名称、住址必须能用于送达。
- 诉讼请求**可执行、可量化**：金额诉请要写明本金 + 利息（起算日、利率、止付日）；行为诉请要明确"做什么、做到什么程度"。
- 事实与理由按时间或逻辑顺序展开，每段引用对应证据编号。
- 法律依据放在事实之后或独立段落，**精确到款项**。
- 管辖法院名称必须正确（全称）。

## 二、民事答辩状

```
民 事 答 辩 状

答辩人：[同上格式]
被答辩人：[同上格式]

答辩人因 [被答辩人] 诉答辩人 [案由] 一案，现提出答辩意见如下：

答辩意见：
一、[针对原告诉请逐一答辩]：原告第 X 项诉请缺乏事实和法律依据，应予驳回。理由是……
二、[管辖异议如有，单独提出，不得在答辩状中合并]
三、[反诉如有，另行提交反诉状]

事实与理由：
[逐一反驳原告事实陈述，引用我方证据]
[提出我方法律观点：抗辩事由、请求权消灭事由、合同效力问题、诉讼时效抗辩等]

综上，请求贵院依法驳回原告的全部诉讼请求。

此致
[XXX 人民法院]

答辩人（签名/盖章）：___________
日期：________年____月____日
```

### 答辩状要点
- **答辩期 15 日**（涉外 30 日），逾期不答辩不影响审理但丧失主动陈述机会。
- **管辖异议须在答辩期内单独提出**（《民事诉讼法》第 130 条），切勿与实体答辩合并。
- **反诉**应在举证期届满前提出，与本诉具有牵连关系。
- 答辩思路：先程序（管辖、主体、时效），再实体（事实、法律）。

## 三、民事上诉状

```
民 事 上 诉 状

上诉人（一审 [原告/被告]）：[XXX]
被上诉人（一审 [原告/被告]）：[XXX]

上诉人因与被上诉人 [案由] 一案，不服 [XXX 人民法院]（YYYY）X 民初 X 号民事判决，现提出上诉。

上诉请求：
一、请求依法撤销 [XXX 人民法院]（YYYY）X 民初 X 号民事判决第 X 项；
二、请求改判……（或：发回重审）；
三、一、二审诉讼费由被上诉人承担。

上诉理由：
一、一审认定事实错误：……
二、一审适用法律错误：……
三、一审违反法定程序：……（如有）

综上，请求二审法院依法支持上诉人的上诉请求。

此致
[XXX 人民法院]（应当通过原审法院递交）

上诉人（签名/盖章）：___________
日期：________年____月____日
```

### 上诉状要点
- **上诉期**：判决 15 日，裁定 10 日，自送达次日起算（涉外当事人 30 日）。⚠️ **绝对不可逾期**。
- **递交方式**：通过原审法院递交，由原审法院移送二审法院。
- **上诉理由**应当对应《民事诉讼法》关于二审审理范围的规定（事实/法律/程序）。

## 四、代理意见 / 代理词

```
代 理 意 见

尊敬的审判长、审判员：

[XX 律师事务所] 接受 [XXX] 的委托，指派本律师作为其与 [XXX][案由] 一案的诉讼代理人，依法出席今天的庭审。结合庭审查明的事实和相关法律规定，发表如下代理意见：

一、关于 [争议焦点 1] ：
（一）事实层面：……
（二）法律层面：……
（三）结论：……

二、关于 [争议焦点 2]：
……

三、关于 [争议焦点 3]：
……

综上所述，[当事人] 的诉讼请求 [事实清楚、证据确凿、于法有据 / 缺乏事实和法律依据]，请求合议庭依法 [支持 / 驳回] [对方] 的诉讼请求。

谢谢！

代理律师：___________
[XX 律师事务所]
日期：________年____月____日
```

## 五、法律意见书

```
关于 [事项名称] 之
法 律 意 见 书

致：[委托方]
出具方：[XX 律师事务所]
日期：________年____月____日
文号：[XXX 律师事务所]法意字（YYYY）第 X 号

一、事实背景
[简要陈述委托事项的事实背景]

二、委托事项
[明确律师被委托回答的法律问题，分点列出]

三、所依据的资料
1. 委托方提供的：……
2. 律师调取的：……
3. 法律法规及司法解释：……
（特别说明：本意见基于上述资料及现行有效法律出具，对未提供资料的部分及法律变更不承担法律责任）

四、法律分析
（一）关于问题 1：……
（二）关于问题 2：……

五、法律意见
1. ……
2. ……

六、风险提示
1. ……
2. ……

七、声明
1. 本意见仅供委托方就本事项使用，不得用于其他目的，不得提供给第三方。
2. 本意见基于截至出具日的中华人民共和国大陆地区现行有效法律。
3. ……

[XX 律师事务所]（盖章）
经办律师：___________（签名）
```

### 法律意见书要点
- 假设与依据要写清楚：基于"客户提供的资料完整真实"的假设。
- 区分**法律意见**与**商业建议**。
- 对每一项法律问题给出明确结论 + 不确定性说明。
- 风险提示应当具体可操作。

## 六、律师函

```
律 师 函

[文号：(YYYY)XX 所律函字第 X 号]

致：[XXX]
（联系地址：____）

[XX 律师事务所] 接受 [XXX]（以下简称"委托人"）的委托，指派本律师就委托人与贵方之间 [事项] 的相关事宜，特此致函如下：

一、事实陈述
……

二、法律分析
根据《XXX》第 X 条之规定，……

三、本所要求
为维护委托人合法权益，本所特此要求贵方于本函送达之日起 [X] 日内，[具体行为]。逾期未履行的，委托人将依法采取以下措施：
1. 向有管辖权的人民法院/仲裁机构提起诉讼/仲裁；
2. 申请财产保全；
3. 追究贵方因此产生的全部经济损失（包括但不限于律师费、诉讼费、保全费、保全担保费、差旅费等）。

特此函告。

[XX 律师事务所]（盖章）
经办律师：___________（签名）
日期：________年____月____日
```

### 律师函要点
- 措辞**严谨克制**，避免威胁、侮辱性语言。
- 主张的事实与法律依据要准确，避免被对方反咬"虚假陈述"。
- 设定明确履行期限和不履行的后果。
- 通过 EMS 或公证送达，保留送达凭证。

## 七、文书自检清单 ⚠️

### 通用项
- [ ] 当事人信息完整、准确（自然人含身份证号；法人含统一社会信用代码、法定代表人）
- [ ] 法院/仲裁机构名称使用全称
- [ ] 案由准确（参照《民事案件案由规定》）
- [ ] 法律依据精确到款项，且现行有效
- [ ] 金额、日期、人名前后一致
- [ ] 没有错别字、标点符号规范
- [ ] 落款、签名、盖章位置预留
- [ ] 附件清单与正文引用一一对应
- [ ] 份数 = 法院 1 份 + 对方人数 + 自留 1 份

### 起诉状专项
- [ ] 诉讼请求每一项都有对应的事实和法律依据
- [ ] 金额请求计算到元，利息有起算日、利率、止付日
- [ ] 行为请求明确具体内容
- [ ] 管辖法院正确（级别 + 地域 + 协议/专属）
- [ ] 标的额计算与诉讼费预交一致

### 答辩状专项
- [ ] 在答辩期内（15 日 / 涉外 30 日）
- [ ] 管辖异议（如有）单独提出
- [ ] 反诉（如有）单独提交反诉状
- [ ] 已逐一回应原告诉请

### 上诉状专项 ⚠️ 期限不可逾越
- [ ] 在上诉期内（判决 15 日 / 裁定 10 日 / 涉外 30 日）
- [ ] 通过原审法院递交
- [ ] 上诉理由对应法定二审审查范围
- [ ] 已交纳上诉案件受理费
